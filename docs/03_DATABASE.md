# DATABASE.md

## Database

Engine: PostgreSQL

ORM: SQLAlchemy

Naming: snake_case

Primary Keys: UUID

Timestamps: UTC

Soft Delete: Yes

---

# Design Principles

- Project First
- Normalized Schema
- UUID Primary Keys
- No Business Logic
- Foreign Keys Everywhere
- Soft Delete Support
- Audit Ready
